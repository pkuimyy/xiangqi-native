# 皮卡鱼分析使用指南

适用于当前 WinUI 原生版本。界面入口位于顶部“分析”选项卡。可查看[分析入口示例](assets/engine-controls.png)。

## 第一次分析

1. 启动 build/winui/Release/XiangqiNative.exe。保留初始局面，或通过“文件 → 打开…”载入一份单局棋谱。
2. 点击顶部“分析”。
3. 先把“深度”改为 **6**，点击“开始分析”。当前默认深度为 15，首次确认功能时建议先用较小深度。
4. 底部应显示“皮卡鱼正在分析…”，“开始分析”按钮暂时不可用。
5. 等待本次搜索完成。右侧棋谱下方会显示深度、评分和最佳走法，棋盘上出现绿色最佳走法箭头。
6. 点击棋盘继续推演，或使用下方前后着按钮切换局面。需要评估新局面时，再次点击“开始分析”。

当前是“分析当前局面”模式，结果在搜索结束后统一显示。分析期间可能保留此前的评分；运行状态以底部提示和按钮是否可用为准。引擎给出建议后，棋子不会自动移动。

## 引擎文件和选择方式

本机的 Release 已包含：

    build/winui/Release/engines/
      Pikafish-Windows-x86-64-universal.exe
      pikafish.nnue
      Copying.txt
      NNUE-License.md

应用启动时会自动发现上面的引擎。直接点击“开始分析”即可，不需要每次选择。

如需手动指定，点击“分析 → 选择引擎”，选择皮卡鱼的 exe。请将配套的 pikafish.nnue 放在 exe 同一目录；程序会以该目录作为引擎工作目录。正在分析时，先停止，等按钮恢复后再更换引擎。手动选择的外部路径目前不会跨重启保存。

若 engines 目录缺失，可在项目根目录运行：

    .\scripts\setup-engine.ps1 -Configuration Release

脚本安装项目固定的 Pikafish-2026-09-06，并校验下载包 SHA-256。复制程序到其他位置时，保留完整应用目录和 engines 子目录。

## 如何看结果

| 显示内容 | 含义 |
| --- | --- |
| 深度 6 | 这次搜索返回的深度；不是预计运行秒数 |
| +0.50 | 应用统一按红方视角展示的正向评分，红方较有利 |
| -0.50 | 黑方较有利 |
| +M… / -M… | 引擎返回了将杀类评分；符号仍以红方为视角 |
| 最佳走法 h2e2 | 建议从 h2 走到 e2；对应棋盘上的绿色箭头 |

普通分数按引擎 cp 值除以 100 展示，不是胜率。棋盘翻转不会改变评分符号。

左侧红黑状态条始终表示“当前由哪方行棋”，与引擎评分无关。

如果切回一个已有评估的节点，会看到该节点之前保存的结果；“已保存评估”表示该结果未带深度信息。

## 建议按这个顺序试用

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 基本分析 | 初始局面，深度 6，开始分析 | 返回深度、评分及最佳着箭头，开始按钮恢复 |
| 黑方行棋 | 红方走一着，再分析 | 结果对应新局面，正负仍统一按红方视角 |
| 翻转 | 翻转棋盘 | 箭头位置随棋盘翻转，评分符号不变，棋盘尺寸不变 |
| 主动停止 | 开始一次搜索，尚未结束时点击“停止” | 底部先提示正在停止，随后恢复开始按钮；本次中止结果不会写回 |
| 切换局面 | 分析未完成时使用前后着按钮 | 旧搜索被取消，旧结果不会写入新局面；可在新局面重新分析 |
| 提高深度 | 基本流程正常后尝试 10、12、15 | 根据机器性能等待更长时间，最终返回新的结果 |
| 保存 | 分析完成后“文件 → 保存”，再重新打开 OXQ | 对应节点的评估、深度和最佳着信息保留 |

停止、切换局面测试需要在搜索结束前操作。深度 6 可能很快结束，可适当提高深度来观察。当前单次分析使用约 60 秒搜索超时限制；达到上限报错时，降低深度重试。

保存注释按钮只更新当前棋谱内容；需要持久保存棋谱、注释和分析结果时，使用“文件 → 保存”。目前界面只管理一份单局棋谱，多局文件会被提示拒绝打开，不会覆盖当前棋谱。

## 常见情况

| 现象或提示 | 处理方法 |
| --- | --- |
| 点击开始后出现文件选择框 | 自动发现目录中没有找到引擎，手动选择 exe |
| Engine executable does not exist / Cannot launch engine | 检查所选路径、文件是否被移动，以及 Windows 是否阻止运行该文件 |
| Engine exited / Engine output closed | 检查 exe 与配套 NNUE 是否齐全、版本是否匹配，再重新选择引擎 |
| Engine response timeout | 先用深度 6 重试；初次握手也有单独的等待上限 |
| Engine returned no legal best move | 当前可能是已结束或无合法着法的局面；退回一着后再试 |
| Engine is not running | 重新选择引擎，再开始分析 |
| 没有实时刷新的深度和分数 | 当前版本在搜索完成后统一更新，查看底部分析状态 |
| 走子后箭头消失 | 新节点没有评估，需要对该局面重新分析 |
| 停止后没有新结果 | 主动停止会丢弃该次搜索结果，保留该节点原有评估 |
| 切换局面后出现“分析已停止” | 这是取消旧局面搜索后的正常提示 |

当前界面提供引擎选择和深度设置；线程数、Hash、多候选主变、连续分析以及人机对弈尚未提供操作入口。

若有异常，请记录：操作步骤、分析深度、底部完整提示，以及“视图 → 复制 FEN”得到的局面。若涉及箭头，再说明是否翻转了棋盘。
