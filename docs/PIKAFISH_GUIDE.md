# 皮卡鱼常驻分析使用指南

当前版本通过“局面分析”面板中的一个开关控制。半屏时它位于棋谱侧栏，宽屏时与图形树和注释一起位于研究区。

## 第一次使用

1. 启动 build/winui/Release/XiangqiNative.exe，保留初始局面，或通过“文件 → 打开…”载入单局棋谱。
2. 打开“局面分析”右侧开关。首次使用默认关闭；以后会记住你上次的选择。
3. 面板先显示“等待当前局面…”，随后显示“持续分析 · 单线程”。
4. 评分、搜索深度、中文主变会逐步更新，棋盘上的绿色箭头表示当前建议着法。
5. 直接走子、前后着导航或选择分支，引擎会自动分析新局面。快速浏览着法时，程序会等短暂停留后再计算。
6. 暂时不需要计算时关闭开关。面板和棋盘保持原有尺寸，可继续查看当前局面上次的结果。

可以查看[当前分析面板示例](assets/engine-controls.png)。

打开开关后会持续加深搜索，没有手动“开始分析”按钮，也没有固定的搜索深度或原先的 60 秒搜索截止。切到视频或其他窗口时仍继续计算。引擎不会自动替你走子。

## 引擎文件与设置

本机 Release 已包含：

    build/winui/Release/engines/
      Pikafish-Windows-x86-64-universal.exe
      pikafish.nnue
      Copying.txt
      NNUE-License.md

应用会自动发现配套引擎。如需选择其他路径，进入顶部“分析 → 选择引擎”，选择皮卡鱼 exe。请把配套 NNUE 放在 exe 同一目录。更换引擎后，开关开启时会自动重新分析当前局面。

开关状态和所选引擎路径保存在下列位置。便携包内的引擎使用相对路径，移动整个应用目录后仍能工作：

    便携 ZIP：应用目录\Data\settings.json
    开发目录（无 portable.flag）：%LOCALAPPDATA%\XiangqiNative\settings.json

当前使用轻量配置：单线程、32MB Hash、较低的进程优先级。线程数、Hash 和多候选主变尚未提供界面设置。

若 engines 目录缺失，可在项目根目录运行：

    .\scripts\setup-engine.ps1 -Configuration Release

脚本安装项目固定的 Pikafish-2026-09-06，并校验下载包。复制应用时请保留完整 Release 目录和 engines 子目录。

## 如何看结果

| 内容 | 含义 |
| --- | --- |
| +0.50 | 红方视角的正向评分，红方较有利 |
| -0.50 | 黑方较有利 |
| 深度 18 | 当前返回的搜索深度，停留在该局面时通常会继续增加 |
| +M… / -M… | 将杀类评分；正负仍以红方为视角 |
| 中文主变 | 第一着是当前建议着法，后面是引擎给出的后续变化 |
| 绿色箭头 | 当前建议着法在棋盘上的位置 |
| 分析已关闭 · 上次结果 | 该局面的上次实时结果或已保存评估，当前没有继续计算 |

普通评分按引擎 cp 值除以 100 显示，不代表胜率。棋盘翻转不会改变分数符号，也不会重新启动搜索；箭头会随棋盘翻转。

左侧红黑状态条只表示当前由哪方行棋，与评分无关。

## 试用顺序

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 初始分析 | 开启开关，停留在初始局面 | 出现评分、深度、中文主变和绿色箭头 |
| 自动跟随 | 红方走一着 | 自动分析黑方行棋的新局面，正负仍按红方视角 |
| 快速浏览 | 连续点击前后着，再停下 | 最终显示停留局面的分析，旧搜索不会写入新局面 |
| 翻转 | 分析中翻转棋盘 | 评分方向保持一致，箭头跟随翻转，棋盘尺寸不变 |
| 关闭 | 关闭面板开关 | 后台停止搜索，保留当前局面的上次结果，布局不跳动 |
| 再开启 | 原地或换到其他局面后开启 | 自动开始当前局面分析 |
| 保存与重开 | 文件 → 保存，再重新打开 OXQ | 当前节点保存的评估、主变和最佳着信息仍可查看 |

实时刷新保存在临时缓存中，不会每次加深都生成撤销记录或把棋谱标记为未保存。执行“文件 → 保存”或“导出 PGN”时，才将**当前节点**最新的实时评估纳入输出。其他节点已经保存的评估会保留；仅浏览产生的其他节点临时结果不会自动批量写入文件。

“保存注释”更新当前棋谱中的注释；需要持久保存整份棋谱时，使用“文件 → 保存”。界面目前只管理单局，多局文件会被提示拒绝打开。

## 常见情况

| 现象或提示 | 处理方法 |
| --- | --- |
| 未配置引擎 | 在顶部“分析 → 选择引擎”中选择 exe |
| 等待当前局面… | 正在防抖、停止旧搜索或准备新搜索；稍作停留 |
| 当前局面已结束 | 当前没有合法着法，不启动搜索；退回一着可继续 |
| Engine executable does not exist / Cannot launch engine | 检查引擎路径及文件是否被移动 |
| Engine exited / Engine output closed | 检查 exe 与 NNUE 是否齐全、版本匹配，然后重新选择引擎 |
| Engine response timeout | 引擎启动或就绪检查未及时回应；检查 NNUE 与引擎，再关闭／开启开关重试 |
| 评分暂时不再变化 | 可能已稳定、找到将杀或本轮搜索已结束；结合状态和深度判断 |
| 切换后暂时显示上次结果 | 该局面有历史结果，后台正在继续更新；不会使用其他局面的结果 |

将鼠标放在面板状态文字上可查看完整提示。发生异常时，请记录操作步骤、完整提示，以及“视图 → 复制 FEN”得到的局面；涉及箭头时请说明是否翻转棋盘。
